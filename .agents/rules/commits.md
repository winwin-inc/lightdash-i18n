# 提交信息规范

适用于本仓库所有提交（含 agent 生成的提交）。

## 标题（首行）

- 格式：`type(scope): 摘要`。scope 用包名或模块名（frontend / backend / common / dashboard / charts / i18n / docs …）
- 长度：≤ 50 字符为宜，**硬上限 72 字符**
- 祈使句概括「改了什么」，不带句号
- **禁止把细节塞进标题**：不用「——」「；」「，」串第二、第三件事；一个提交只说一件事，多件事拆多个提交

## 正文

- 标题与正文之间空一行；标题放不下的细节一律进正文
- 正文回答「为什么改、怎么改、影响什么」：动机、方案要点、边界情况、测试与生成物同步情况
- 每行 ≤ 72 字符，手动换行；并列要点用 `-` 列表，一项一条

## 反例 → 正例

❌ 标题塞满细节：

```
fix(dashboard): 约束编辑器 UI 再优化——开关文案区分（按数据更新限制最早/最晚）、N 输入框缩小（44×26）、动态状态改为输入行内联小字、去掉单独 Badge 行、顶部无意义空白收紧（mt 16→4）
```

✅ 标题一行说清，细节进正文：

```
fix(dashboard): 约束编辑器 UI 细节优化

- 开关文案区分（按数据更新限制最早/最晚）
- N 输入框缩小（44×26）
- 动态状态改为输入行内联小字（动态：xx–xx / 固定窗口（不滚动））
- 去掉单独 Badge 行
- 顶部空白收紧（mt 16→4）
```

## 历史超长标题

已推送/已合入的历史提交不改写；本规范只约束新提交。

## 2. 已上线 / 已落地能力（备份清单）

下列能力已在本产品落地（代码已接线）。下列开关**未设 env 即默认开启**；设 `=false` 并重启服务后关闭。

### 2.1 可由环境变量关闭的能力

开关配在服务端环境（backend / 根 env），改完需重启服务。语义：未设置 / 空 → **开**；`false` → 关。

| 环境变量 | 已上线能力说明 |
|----------|----------------|
| `MERGE_QUERIES_ENABLED`（默认开） | Explore **合并查询**：跨 explore join、Run、保存与重开 |
| `DASHBOARD_TABS_IN_MEMORY`（默认开） | 看板 **Tab 内存**：已访问 Tab 切回时减少整页闪断重建 |
| `LOCK_DASHBOARD_FILTERS_ENABLED`（默认开） | 看板 **筛选锁定**：编辑态锁定后，view 下 URL 强改锁定项被忽略并提示 |
| `ENABLE_TIMEZONE_SUPPORT`（默认开） | **时区能力总开关**（界面不可单独开），详见 2.3 |
| `RESULTS_CACHE_ENABLED`（默认开） | 项目 **结果缓存 TTL** 设置（如缓存设置页可读可写） |
| `APPS_RUNTIME_ENABLED`（默认开） | **Data Apps 运行时入口**（导航 / 权限 / 看板磁贴）；Sandbox 真跑、AI 生成端到端 **未作为交付、不测** |

### 2.2 不依赖上述开关即可用的能力

**Explore / 分析**

1. **Formula 表计算**：公式模式、校验、Run、保存持久化；标量公式可配合 totals。  
2. **同期对比（PoP）**：有时间维时可加对比列；无时间维时入口不可用或有提示。  
3. **透视 · 冻结列**：表格可冻/解冻列；存在透视维度时冻列按钮按规则隐藏；透视列上限仍为 150。  
4. **透视 · 合并重复行值**：表格可开合并重复行值展示。

**看板**

5. **Date Zoom（基础）**：顶栏切换日/周/月等，改变带日期维图表的时间聚合颗粒（非筛选器）。属体验增强，非刚需。  
6. **看板 Owner**：编辑态可指定所有者；组织删用户时可转让或留空。历史未写 owner 的看板，按 owner 汇总可能为空（预期现象）。  
7. **看板导出 XLSX**：支持分文件 ZIP / 单个工作簿（多 sheet）。  
8. **定时推送 XLSX**：同上两种布局选项。

**体验 / 权限 / 中文**

9. **Omnibar**：中文 1 字可检索（不必凑满 3 字符）。  
10. **截图 CJK 字体**：定时/分享截图中文可读。  
11. **Custom SQL 表计算权限**：无管理权限时 SQL 模式禁用并提示。  
12. **关键中文**：公式 Modal、Data Ops 分组等已中文化，避免裸英文 key。

**数据集分组（配置 + CLI）**

13. **Nested Table Groups**  
    - 模型 `meta.groups`（string 数组，多层）+ 可选保留 `group_label`（兼容单层）。  
    - 项目 `lightdash.config.yml` 的 `table_groups` 提供中文标签。  
    - 需使用与服务端同代的 CLI 执行 deploy/preview 后 Explore 侧边栏生效。  
    - 仅影响侧边栏归类，**不改** explore/表名，不影响按表名的历史查询。

### 2.3 时区能力明细（默认开；`ENABLE_TIMEZONE_SUPPORT=false` 可关）

1. 项目查询时区可配置并保存。  
2. Explore / 图表可选项目时区、用户时区等。  
3. 时间维截断与日期筛选可按项目时区感知。  
4. 用户资料默认时区。  
5. 仓库连接「数据时区」及 Preview。  
6. 结果区 resolvedTimezone 标注（MVP Badge）。

### 2.4 验收时可用的简要步骤（备份）

| 能力 | 怎么确认已上线可用 |
|------|--------------------|
| 合并查询 | Explore 有合并入口 → join → Run → 保存重开仍在 |
| Tab 内存 | 多 Tab：A→B→A，A 不整页闪断重建 |
| 锁筛选 | 编辑锁定 → view 打开带 filters 的链接 → 锁定项不被覆盖 |
| 时区 | 默认开：项目/图/用户/仓库时区与 Badge 可见 |
| 结果缓存 | 项目缓存 TTL 可改 |
| Data Apps | 能进列表、能加看板磁贴即可 |
| Formula / PoP / 透视 | 按上节功能点各走通一次 |
| Owner / XLSX | 编辑指定 Owner；导出与定时可选 ZIP 或单工作簿 |
| Nested Groups | 新 CLI deploy 后侧边栏见多层分组（如 前端→哪吒AI） |

## 3. 明确不需要实现 / 本窗口不交付（备份）

以下能力在上游 **2.57.0 窗口内可能存在或更完整**，但本产品 **明确不实现或不作为本窗口交付**。勿当作漏做缺陷。

| 类别 | 项 | 说明 |
|------|-----|------|
| 体验配置 | 必填筛选 **GuidedSetup** 向导 UI | 语义/拦截可另有基础能力；向导 UI 不做 |
| 看板 | Date Zoom **增强**（`dateZoomConfig`、控件配置化等） | 基础 Date Zoom 已有；增强与动态日期/Tabs 冲突大，不做 |
| 链接治理 | Chart / Content **Slug 重命名**（改名保旧链 / CLI slugUpdate 闭环） | 可用 slug 打开 ≠ 本项；边缘需求，不做 |
| 嵌入 | **Embed 解绑**（无商业 License 也完整嵌入） | Embed 属商业能力路径；本窗口不解绑专项 |
| EE | **Pre-aggregates** 预聚合 | EE，不做 |
| 权限 | **Role Sets** 等 | 冲突/专项，本窗口不做 |
| 数据 | **External Sources** | 不做 |
| 图表 | **Project Chart Types** 全量 | 依赖 Data Apps 深挖，不做全量 |
| Data Apps | Sandbox 真跑通、AI **generate** 端到端 | 仅运行时入口级；深挖不做 |
| 时区 | echarts 完整 **timezoneShift** | 破坏面大，后置/不做本窗口交付 |
| 工程策略 | 整仓 rebase / 对齐上游 **2.57 全量** 每一个功能 | 禁止；只模块化移植 |

补充（旧能力回归，非本窗口「新增交付」备份重点）：

- 多 Tab「隐藏 Tab」、URL `?filters=` 深链细节、全局/Tab 筛选叠加等——若需回归另列，不记入本窗口「新上线清单」。

## 4. CLI / 分组配置兼容（备份备忘）

| 组合 | 预期 |
|------|------|
| 新 CLI + 新服务端 + `groups` + `table_groups` | 多层分组正常 |
| 旧 CLI + 保留 `group_label` 的新 schema | 一般可 deploy；仅单层分组 |
| 新 CLI + 旧服务端（无 table-groups 等接口） | deploy 可能失败，勿对旧生产强推 |
| 仅改分组 meta | 不改表名，历史按表名查询不受影响 |

建议模型双写：`group_label` + `groups`，避免旧 CLI 丢分组。

> 2026-09-09 · 产品版本以 `package.json` 为准（如 **2.0.2**）

> 给业务用户看的短版：[`CHANGELOG.md`](CHANGELOG.md)

## 升级后即可使用（无需开关）

- **公式表计算**：用公式写计算列，可校验、运行、保存。
- **同期对比**：有时间维度时可加「上一期」对比列。
- **透视冻列 / 合并重复行**：表格可锁列、合并相同行标签；有透视时冻列按钮会隐藏。
- **时间粒度**：看板顶栏可切日 / 周 / 月，图按新粒度聚合（不是改筛选范围）。
- **看板所有者**：可指定负责人；删用户时能转让。
- **Excel 导出与定时推送**：支持多文件 ZIP，或一个工作簿多个 sheet。
- **搜索与中文**：1 个中文字即可搜索；截图中文可读；公式等界面已中文化。
- **数据集分组**：配套 CLI deploy 后，Explore 侧边栏可多层收纳（如「前端 → 哪吒AI」），不改表名。建议同时保留原来的 `group_label`，旧 CLI 仍能显示单层分组。

## 默认开启（可用 `=false` 关闭）

未设置或空值时默认 **开启**；仅当设为 `false`（大小写不敏感）并重启后端后关闭。关闭时界面不出现对应入口，不影响现有用法。

| 环境变量 | 功能 |
|----------|------|
| `MERGE_QUERIES_ENABLED` | **合并查询**：把两张数据集按字段拼在一起分析。 |
| `DASHBOARD_TABS_IN_MEMORY` | **Tab 更流畅**：多 Tab 切回去时少整页重载。 |
| `LOCK_DASHBOARD_FILTERS_ENABLED` | **锁定筛选**：锁住的条件不会被分享链接改掉。 |
| `ENABLE_TIMEZONE_SUPPORT` | **时区**：可配项目 / 用户 / 图表时区，结果会标明实际时区。只能用环境变量打开。 |
| `APPS_RUNTIME_ENABLED` | **数据应用入口**（默认关，仅 `=true` 时开）。本版本**不交付**生成与沙箱运行；生产建议保持 `=false`。详见 [`v2-data-apps.md`](v2-data-apps.md)。 |

发版建议：预发可先打开上表除 Data Apps 外的项；生产按业务需要逐项开。生产若暂不开放数据应用，保持 `APPS_RUNTIME_ENABLED=false`。

## 本版本不包含

上游窗口里有、本版本不做。避免按已上线功能验收。

| 项 | 原因 |
|----|------|
| 必填筛选配置向导 | 拦截逻辑已有，向导界面未做 |
| 可配置的时间粒度增强 | 基础切换已有；和动态日期、多 Tab 容易打架 |
| 改网址别名并保住旧链接 | 现有 slug 能打开即可；改名保旧链需求少、容易弄坏书签 |
| 对外嵌入看板（免登录） | 依赖商业授权路径，本版本不解绑 |
| 预聚合 | 商业能力，本版本不做 |
| 外部数据源、自定义图表类型全量 | 依赖未收口的数据应用深挖 |
| 数据应用 | 入口已合入，生成 / 沙箱 / 可用预览未收口，不作为本版本功能交付 |
